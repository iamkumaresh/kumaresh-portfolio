
# Kumaresh Jana | Portfolio

[](https://react.dev/)
[](https://vitejs.dev/)
[](https://tailwindcss.com/)

A high-performance, responsive professional portfolio built with **React**, **TypeScript**, and **Motion**. This site showcases my expertise in Java, Data Structures & Algorithms (DSA), and Frontend Development as a 2nd-year CSE student at JIS University.

## 🚀 Features

  Modern UI/UX: Built with Tailwind CSS 4 and Motion for smooth, high-fidelity animations.
  Theme Switching: Support for native Light and Dark modes.
  AI Integration: Pre-configured to work with the **Gemini AI API**.
  Responsive Design: Fully optimized for mobile, tablet, and desktop viewing.

## 🛠️ Technical Stack

  Frontend: React 19, TypeScript, Tailwind CSS, Lucide React (Icons).
  Animations: Motion (framer-motion).
  Build Tool: Vite.
  Backend/Logic: Java (DSA focus), Node.js (Environment).



## 💻 Local Setup

### Prerequisites

  Node.js (Latest LTS recommended)
  NPM (Comes with Node.js)

### Installation

1.  **Clone the repository**:

    ```bash
    git clone https://github.com/iamkumaresh/Portfolio.git
    cd Portfolio
    ```

2.  **Install dependencies**:

    ```bash
    npm install
    ```

3.  **Configure Environment Variables**:

      * Create a `.env.local` file in the root directory.
      * Add your Gemini API Key:
        ```env
        GEMINI_API_KEY="your_api_key_here"
        ```

4.  **Run the development server**:

    ```bash
    npm run dev
    ```

    The app will be available at .
